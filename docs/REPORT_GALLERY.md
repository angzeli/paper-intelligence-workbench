# Report Gallery

Reports are generated from local registry, BibTeX, notes, claims, themes, files, and caches. They are reproducible from local inputs and do not call external services.

Use `--force` only when intentionally replacing an existing report.

| Report | Purpose | Command | Inputs | Example output | Interpretation boundary |
| --- | --- | --- | --- | --- | --- |
| Inventory | Show registry contents and validation context | `paperwb report inventory --registry data/registries/example_papers.csv --out scratch/inventory.md --force` | registry, optional notes | `reports/inventory.md` | Does not verify that metadata is scientifically correct |
| Reading status | Summarize unread, skimmed, read, and deeply read papers | `paperwb report reading-status --registry data/registries/example_papers.csv --out scratch/reading_status.md --force` | registry | `reports/reading_status.md` | Uses user-entered status values |

| Citation audit | Find citation-readiness gaps across registry, notes, claims, themes, and BibTeX | `paperwb report citation-audit --registry data/registries/example_papers.csv --bibtex data/bibtex/example_library.bib --notes-dir data/notes --themes data/examples/themes.json --out scratch/citation_audit.md --force` | registry, BibTeX, notes, themes | `reports/citation_audit.md` | Audits completeness, not scientific truth |

## Reading A Report

Treat reports as checklists over your own local information. If a claim is missing a page, if a paper lacks a note, or if a theme relies only on review statements, the tool is reporting an evidence-tracking gap. It is not judging whether a scientific conclusion is true.
