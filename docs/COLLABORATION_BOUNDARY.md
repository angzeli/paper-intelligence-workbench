# Collaboration Boundary

Paper Intelligence Workbench collaboration is local and file based.

Allowed:

- export a review packet directory
- share Markdown, CSV, and JSON packet files manually
- import reviewer comments from CSV
- generate response-to-review and follow-up reports

Not allowed in this project boundary:

- cloud collaboration
- automatic email sending
- LLM review or rewriting
- automatic evidence edits from reviewer comments
- treating comments as scientific truth
- including PDFs in review packets by default

The project owner remains responsible for deciding whether a comment should
lead to rereading, softer wording, stronger evidence, or citation cleanup.
