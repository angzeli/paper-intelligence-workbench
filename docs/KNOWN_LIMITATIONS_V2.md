# Known Limitations v2

- The CLI is broad and can overwhelm first-time users.
- BibTeX parsing is intentionally lightweight, not a complete BibTeX engine.
- Markdown note parsing is conservative and template-oriented.
- Draft and manuscript evidence matching is lexical and heuristic.
- Report formats are optimized for human review, not stable machine APIs.
- SQLite index files are rebuildable caches.
- Backup, migration, and sync workflows should stay dry-run-first.
- Synthetic fixtures intentionally contain warnings and validation errors.
- The tool does not parse real PDFs, OCR scans, scrape websites, or generate
  final literature-review prose.
