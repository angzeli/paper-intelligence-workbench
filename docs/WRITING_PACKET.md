# Writing Packet

A writing packet combines the authoring reports for one theme:

- section outline
- evidence matrix
- claim bank
- citation bank
- paragraph plan
- subsection readiness

Generate one with:

```bash
paperwb writing-packet --project zis_photocatalysis --theme photocorrosion --out reports/photocorrosion_writing_packet.md --force
```

Use the packet as a pre-drafting review. It should make unsupported or weak claims visible before the user writes a final subsection.

The packet explicitly does not fabricate claims, citations, quotes, summaries, or final prose.
