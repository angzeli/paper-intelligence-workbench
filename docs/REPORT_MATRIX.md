# Report Matrix

| Report | Purpose | Main command | Inputs | Output | Boundary |
| --- | --- | --- | --- | --- | --- |
| Inventory | Paper list and registry validation context | `paperwb report inventory` | registry, notes | Markdown | Does not verify paper truth |
| Reading status | Reading-progress summary | `paperwb report reading-status` | registry | Markdown | Uses user-entered status |
| BibTeX audit | Citation-entry completeness | `paperwb report bibtex-audit` | BibTeX, registry | Markdown | Does not auto-correct entries |
| Claims by theme | Theme grouping from notes | `paperwb report claims-by-theme` | notes, themes | Markdown | Tag/theme mapping only |
| Evidence map | Theme evidence coverage | `paperwb report evidence-map` | registry, notes, BibTeX, themes | Markdown | Completeness audit, not truth score |
| Citation audit | Citation-readiness gaps | `paperwb report citation-audit` | registry, notes, BibTeX, themes | Markdown | Does not judge scientific validity |
| Missing notes | Papers lacking parsed notes | `paperwb report missing-notes` | registry, notes | Markdown | Path/parse audit only |
| Weak claims | Weak or low-confidence claims | `paperwb report weak-claims` | notes, themes | Markdown | Uses user-entered claim metadata |
| Theme dashboard | Theme coverage table | `paperwb report theme-dashboard` | claims, themes | Markdown | Heuristic coverage summary |
| Evidence matrix | Claim-by-paper matrix | `paperwb report evidence-matrix` | claims, registry, BibTeX | Markdown, CSV, JSON | Planning aid |
| Claim bank | Strong/moderate/weak claim buckets | `paperwb report claim-bank` | claims, themes | Markdown | Does not rewrite claims |
| Citation bank | Papers grouped by use role | `paperwb report citation-bank` | registry, claims, BibTeX | Markdown | Role assignment is rule-based |
| Paragraph plan | Suggested paragraph purposes | `paperwb report paragraph-plan` | claims, themes | Markdown | Skeleton only, not final prose |
| Writing packet | Combined authoring aid | `paperwb writing-packet` | authoring reports | Markdown | User must write final section |
| Draft audit | Manuscript citation/evidence audit | `paperwb draft audit` | Markdown draft, registry, notes, BibTeX, themes | Markdown | Heuristic support audit, not truth evaluation |
| Draft citation coverage | Citation-key coverage table | `paperwb draft citations` | Markdown draft, registry, BibTeX | Markdown | Checks local linkage only |
| Paragraph evidence matrix | Paragraph-to-claim match table | `paperwb draft evidence-matrix` | Markdown draft, claims, themes | Markdown | Keyword/tag/theme overlap only |
| Revision checklist | Manual draft revision tasks | `paperwb draft checklist` | Draft audit findings | Markdown | Does not rewrite prose |
| Manuscript QA | Reviewer-style manuscript citation and evidence audit | `paperwb manuscript qa` | Markdown or LaTeX-ish draft, registry, notes, BibTeX, themes | Markdown | Heuristic support audit, not truth evaluation |
| Citation context table | Citation occurrence to local claim context | `paperwb manuscript context-table` | Draft, registry, notes, claims | Markdown | Heuristic matching only |
| Claim traceability | Tracked-claim usage in draft paragraphs | `paperwb manuscript trace-claims` | Draft, claims, themes | Markdown | Checks usage, not claim truth |
| Manuscript revision checklist | Manual revision tasks from manuscript QA findings | `paperwb manuscript checklist` | Manuscript QA findings | Markdown | Does not rewrite prose |
| Rule report | Built-in and project-specific rule findings | `paperwb rules report` | rules.json, registry, notes, BibTeX, themes, optional manuscript | Markdown | Local validation only; does not modify user data |
| Rule config audit | Declarative rule config validation | `paperwb rules validate-config --out` | rules.json | Markdown | Validates schema and supported condition types only |
| File audit | Local-file reconciliation | `paperwb files audit` | registry, files.csv, local folders | Markdown | Does not parse PDF full text |
| Search report | Search-result export | `paperwb search QUERY --out` | registry, notes, index | Markdown | Transparent lexical/indexed ranking |
| Release readiness | Release summary | generated by maintainer scripts | test/CLI/report outputs | Markdown | Snapshot of local release state |
