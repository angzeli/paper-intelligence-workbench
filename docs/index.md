# Paper Intelligence Workbench Documentation

Paper Intelligence Workbench is a local-first CLI for literature-review evidence tracking. It manages registry rows, BibTeX keys, structured notes, user-written claims, evidence reports, draft QA, reading workflows, backups, compatibility checks, and sanitized diagnostics.

It does not read papers for you, scrape publishers, use cloud or LLM APIs, fabricate claims, judge scientific truth, or write final prose.
