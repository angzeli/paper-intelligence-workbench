# Report Gallery v3

Reports are Markdown artifacts generated from local data. They are intended for
inspection and review, not as stable machine APIs.

## Stable Core Reports

- Inventory: `paperwb report inventory`
- Reading status: `paperwb report reading-status`
- BibTeX audit: `paperwb report bibtex-audit`
- Evidence map: `paperwb report evidence-map`
- Citation audit: `paperwb report citation-audit`
- Weak claims: `paperwb report weak-claims`
- Missing evidence: `paperwb report missing-evidence`
- Theme checklist: `paperwb checklist`
- Dashboard: `paperwb dashboard --out`

## Experimental Reports

- Draft and manuscript QA reports.
- Evidence graph summaries and exports.
- Claim lifecycle queues and contradiction reports.
- Workflow run reports.
- Review packet and response-to-review reports.
- Sync plans and conflict reports.
- Incremental rebuild plans.
