# Post-v2.0 Roadmap

## High Priority

- Dogfood one real local project from template to citation audit.
- Simplify public docs after seeing where users hesitate.
- Keep dry-run, force, backup, and overwrite behavior under tests.

## Medium Priority

- Improve report discoverability.
- Add more command-contract tests for experimental commands before stabilizing
  them.
- Improve onboarding for empty template warnings.

## Low Priority

- Optional richer local search ranking.
- More template domains, but only with empty/synthetic scaffolds.

## Explicitly Not Planned

- Cloud sync.
- LLM summarization.
- Publisher scraping.
- Default PDF full-text extraction or OCR.
- Web app rewrite.
