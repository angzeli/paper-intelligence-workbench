# FYP Photocatalysis Theme Pack v2.0

## Purpose

The v2.0 dogfood workflow adds an expanded empty theme pack for FYP-style
photocatalysis literature reviews. Themes organize user-entered evidence; they
are not claims and do not imply scientific conclusions.

## Themes

| Theme | Intended Use |
| --- | --- |
| Metal sulfide photocatalysts | Broad material family context |
| ZnIn2S4 structure and phases | Structure, phase, and composition tracking |
| Precursor chemistry | Chemistry before film/material formation |
| Xanthate-derived thin films | Xanthate-specific thin-film route |
| Thin-film fabrication | Fabrication and deposition methods |
| Film morphology | Surface, grain, and morphology evidence |
| Charge separation | Photocarrier and interfacial charge evidence |
| Heterojunctions | Interface and band-alignment evidence |
| Cocatalysts | Surface-active-site and loading evidence |
| Co-Pi and CoOx | Cobalt cocatalyst evidence |
| Photocorrosion and stability | Degradation and durability evidence |
| CO2 adsorption and activation | CO2 surface interaction evidence |
| CO2 reduction products | Product distribution evidence |
| Selectivity | Selectivity and competing reactions |
| Sacrificial agents | Hole scavenger and sacrificial chemistry context |
| Reactor configuration | Reactor and cell design considerations |
| Characterization methods | XPS, XRD, microscopy, spectroscopy, and related methods |
| Quantum efficiency | AQE and conversion-efficiency evidence |
| Limitations and controls | Controls, gaps, and reproducibility checks |

## Boundary

The pack is empty. It includes no real paper metadata, no claims, no citations,
no quotes, no PDFs, and no copied article text.
