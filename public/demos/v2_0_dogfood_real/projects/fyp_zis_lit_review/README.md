# Synthetic FYP ZIS Literature Review Demo

This project is a synthetic public scaffold for the photocatalysis dogfood
workflow. Replace placeholder rows with verified user-entered metadata before
using it for a real literature review.

Recommended first steps:

1. Add one verified paper to `registry.csv`.
2. Add its BibTeX entry to `bibtex/library.bib`.
3. Run strict registry and BibTeX validation.
4. Generate a note template.
5. Read the paper and enter claims manually.
6. Extract claims and generate evidence/citation reports.
